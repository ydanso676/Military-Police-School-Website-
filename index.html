  • Submit an application when applications are open, then complete the phases to earn this position.

Head Instructor

MIDDLE COMMAND
O5
Lieutenant ColonelO5

Description

Head Instructors manage the database, log phases and events, and handle many other duties. They also host sessions and support both new and existing members of Military Police School.

How to Obtain

  • Be selected by High Command when a position is open.
  • Apply when a Middle Command application is open, then complete the phases to earn this position.

Chief Instructor

MIDDLE COMMAND
O6
ColonelO6

Description

Chief Instructors focus on logging and rank management. They host tryouts and events for Military Police School, and support both new and existing members.

How to Obtain

  • Be selected by High Command when a position is open.
  • Apply when a Middle Command application is open, then complete the phases to earn this position.

Aide-de-Camp

MIDDLE COMMAND
O6
ColonelO6

Description

The Aide-de-Camp serves as an assistant to High Command, observing and stepping in to help whenever High Command needs support.

How to Obtain

  • Be selected by High Command when a position is open.
  • You must already be a member of Middle Command.

Senior Enlisted Advisor

HIGH COMMAND
E9B
Sergeant MajorE9B

Description

The Senior Enlisted Advisor manages and represents the Enlisted Instructors, and oversees Lower Command. They handle quotas, discipline and corrections, advise High Command, and help develop Military Police School.

How to Obtain

  • Be selected by Headquarters and approved by Marine Staff.

HIGH COMMAND

Description

The Vice Chairman oversees Middle Command and recruitment, and assists the Chairman in running Military Police School. They also monitor the state of the school and put forward initiatives that help it grow.

How to Obtain

  • Be selected by Headquarters and approved by Marine Staff.
